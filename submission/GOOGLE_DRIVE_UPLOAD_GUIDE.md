# Google Drive Upload Guide

## What to upload in the Google Drive folder
Place the following items in one shared Google Drive folder:

- Project source code
- README file
- Requirements file
- SQL scripts
- Notebook file
- Screenshots or dashboard images
- Any supporting documentation

## Sharing settings
Before sharing the folder:

- Open the folder settings
- Set access to "Anyone with the link"
- Set permission to "Viewer"
- Make sure the folder is accessible without requiring a Google sign-in

## Final link format
Use a public folder link like:

https://drive.google.com/drive/folders/your_folder_id_here

## Important
Do not use a restricted or private folder. The link must be open and accessible to evaluators.
