# Final Submission Text

## Project Title
Retail Sales Analytics Lakehouse using Databricks and Snowflake

## Category
Data Lakehouse

## Short Description
Retail Sales Analytics Lakehouse using Databricks and Snowflake is a modern analytics project that uses a lakehouse architecture for retail sales data processing and reporting. It integrates Databricks for transformation and analytics workflows, Snowflake for cloud-based data warehousing, and a Streamlit dashboard for visualizing KPIs such as revenue, orders, category performance, monthly trends, and regional sales.

## Detailed Description
This project focuses on building a scalable retail analytics solution to monitor business performance using a lakehouse approach. The system generates synthetic retail sales data, processes it using analytics logic, and presents insights through an interactive dashboard. By combining Databricks and Snowflake, the project demonstrates how raw transactional sales data can be transformed into meaningful business intelligence for decision-making. The dashboard highlights revenue trends, top products, category growth, and regional sales distribution.

## Keywords
Data Lakehouse, Retail Analytics, Databricks, Snowflake, ETL, Data Engineering, Business Intelligence, Dashboard
