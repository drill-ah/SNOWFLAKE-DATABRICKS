# Project Summary for Final Submission

## Project Title
Retail Sales Analytics Lakehouse using Databricks and Snowflake

## Domain / Category
Data Lakehouse

## Short Description
This project implements a retail sales analytics solution built around a modern lakehouse architecture. It uses Databricks for ETL and transformation workflows, Snowflake for analytical data storage and reporting, and a Streamlit dashboard for interactive business intelligence. The solution analyzes revenue, sales trends, regional performance, category contribution, and top-selling products to support retail decision-making.

## Detailed Description
The retail industry depends on accurate and timely performance analysis to drive strategic decision-making. This project focuses on building a scalable analytics pipeline for retail sales data using a lakehouse model that combines both data lake and warehouse capabilities. Synthetic retail sales data is generated and processed to derive core business metrics such as total revenue, total orders, average order value, and monthly trends.

The project demonstrates a complete data workflow starting from raw transactional data, through analytical transformations, to curated insights presented in a dashboard. Databricks is used for processing and lakehouse-style data organization, while Snowflake provides a warehouse-ready reporting layer. The dashboard visualizes trends and KPIs to help stakeholders understand sales performance across categories and regions.

## Key Features
- Retail sales KPI dashboard
- Revenue analysis by category
- Regional sales comparison
- Monthly sales trend analysis
- Top product performance tracking
- Databricks and Snowflake architecture demonstration
- Python-based data generation and analytics workflow
