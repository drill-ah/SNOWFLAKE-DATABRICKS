# Hosted Project Link Guide

## Recommended platforms
- Streamlit Cloud
- Vercel
- Netlify
- Render

## Recommended for this project
Use Streamlit Cloud for the dashboard, since the project contains a Streamlit app.

## Deployment command
```bash
PYTHONPATH=src streamlit run dashboard.py
```

## Before submission
- Deploy the live app
- Check that the dashboard loads successfully
- Confirm all charts render correctly
- Copy the final public URL

## Important
The hosted URL must be public and accessible without login restrictions.
